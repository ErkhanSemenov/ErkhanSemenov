## Featured project

### [Check na udachu](https://github.com/ErkhanSemenov/check-na-udachu-test-ficomp)

A web application for a promotional campaign where users register receipts and moderators review them through Django Admin.

**Stack:** Python 3.12, Django 5.1, PostgreSQL, JavaScript, Docker, Gunicorn, OpenCV, ZXing-C++

Some of the things implemented:

- user authentication and registration
- receipt submission without page reload
- server-side validation and database constraints
- protection against duplicate receipts and race conditions
- PostgreSQL indexes and constraints
- QR-code recognition from images
- user dashboard with pagination and status updates
- moderation through Django Admin
- CSV export
- automated tests
- Docker Compose setup
